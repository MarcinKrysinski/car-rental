# Car Rental

A simulated car rental system: reserve a car of a given type (Sedan, SUV, Van) from a date and
time for a number of days, with a limited number of cars per type.

Java 21, Spring Boot 4, Maven.

## Running

Requires JDK 21.

```bash
./mvnw test
```

```bash
./mvnw spring-boot:run
```

On Windows use `mvnw.cmd` instead of `./mvnw`.
